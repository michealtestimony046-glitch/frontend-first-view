# Matrix QA

> Matrix QA is an evidence-grade browser quality-assurance platform operated by Tr Labs. It runs authorized web journeys in a real browser and organizes screenshots, browser events, console signals, network activity, timestamps, artifacts, reports, and findings for human investigation.

## What Matrix QA does

Matrix QA is designed for authorized browser-based journeys such as login, signup, navigation, forms, and other project-defined critical paths. A project supplies an authorized target URL, journey instructions, a test mode, and, when needed, a dedicated test account. The browser worker performs sequential actions and the platform records evidence around meaningful state changes.

Depending on the run and available storage, evidence can include screenshots, page and browser events, console messages, network requests, response status, timings, logs, videos, reports, and findings. Deterministic signals can include uncaught JavaScript errors, failed selectors, and non-success responses. A report is evidence for the tested journey and captured signals; it is not a guarantee that an application has no defects.

## Authorization and safety

Matrix QA is intended for websites and applications that the customer owns or is authorized to test. Customers remain responsible for target authorization, test accounts, instructions, and review of consequential actions. Do not interpret the public guides as permission to test third-party systems.
